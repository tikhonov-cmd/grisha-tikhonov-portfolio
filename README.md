# Гриша Тихонов — режиссёр

Личное портфолио: четыре фильма с галереями кадров, пролистыванием и увеличением, короткое представление и Telegram.

**Сайт:** https://tikhonov-cmd.github.io/grisha-tikhonov-portfolio/

## Как изменить страницу

- `index.html` — имя, представление, описания фильмов, длительность и ссылки.
- `styles.css` — оформление и мобильная версия.
- `script.js` — галереи и просмотр кадров.
- `assets/frames/` — кадры фильмов; для каждого кадра есть основная и уменьшенная версия.
- `frame-sources.json` — исходные фильмы и таймкоды выбранных кадров.

Фильмы хранятся на Яндекс Диске. На сайт загружены только кадры. У изображений сохранены композиция, пропорции и исходный цвет. Заголовки фильмов очищены от технических суффиксов файлов; годы выпуска не указаны, поскольку не подтверждены.


## Предварительный просмотр

Откройте `index.html` в браузере или запустите в папке сайта:

```sh
python3 -m http.server 4173
```

Затем откройте http://localhost:4173. Установка библиотек и сборка не нужны.

## Размещение

GitHub Pages публикует ветку `main`, папку `/ (root)`. После изменения файлов и отправки в GitHub страница обновляется автоматически.

При переносе в другой репозиторий измените адреса `canonical`, `og:url` и `og:image` в начале `index.html`.
